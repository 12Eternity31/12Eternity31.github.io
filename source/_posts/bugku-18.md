- 附件：一段"社会主义核心价值观"文字

## 2. 题目描述
附件内容长这样：

```
富强 民主 文明 和谐 自由 平等 公正 法治 ...
```

一长串社会主义核心价值观的词语。这就是 **"核心价值观编码"**。

## 3. 解题思路（一句话）
这是一套**把十六进制 0-F 映射成 24 个字核心价值观词**的编码，
有现成解码器，粘进去就出明文。

## 4. 详细步骤

### 4.1 编码原理（先看懂，再看工具）

**核心思路一句话**：
`明文 → UTF-8 字节 → 十六进制字符串 → 把每个 hex 字符映射成中文词`。

具体映射方式主流实现是这样的：24 个词按顺序两两配对，
组成 **16 个"词对"**，每个词对代表一个十六进制字符 `0`~`F`：

| hex | 词对 | hex | 词对 |
|---|---|---|---|
| 0 | 富强民主 | 8 | 自由平等 |
| 1 | 富强文明 | 9 | 自由公正 |
| 2 | 富强和谐 | A | 自由法治 |
| 3 | 富强自由 | B | 自由爱国 |
| 4 | 富强平等 | C | 自由敬业 |
| 5 | 富强公正 | D | 自由诚信 |
| 6 | 富强法治 | E | 自由友善 |
| 7 | 富强爱国 | F | 富强敬业 |

> **别死记这张表！** 不同版本的实现细节有差异，
> **解码一律用在线工具**，把时间花在理解"编码 = 无密钥可逆"这个点上。

**为什么"两个字"能表示一位 hex？**
`16 = 4×4`，理论上一个词最多能表示 4 种状态。
用两个词就可以表示 `4×4 = 16` 种状态，正好覆盖 `0`~`F`。

### 4.3 自己写 Python 解（可选，理解原理）

思路：**把中文词序列还原成 hex 字符串，再 `bytes.fromhex()` 得到原文**。

```python
# 核心价值观解码（主流实现版）
# 24 个词 -> 16 个词对 -> hex 字符
BASE = ['富强', '民主', '文明', '和谐', '自由', '平等', '公正', '法治',
        '爱国', '敬业', '诚信', '友善']

# 构造 16 个词对到 hex 的映射（按主流实现的排列方式）
PAIRS = [
    ('富强', '民主'), ('富强', '文明'), ('富强', '和谐'), ('富强', '自由'),
    ('富强', '平等'), ('富强', '公正'), ('富强', '法治'), ('富强', '爱国'),
    ('自由', '平等'), ('自由', '公正'), ('自由', '法治'), ('自由', '爱国'),
    ('自由', '敬业'), ('自由', '诚信'), ('自由', '友善'), ('富强', '敬业'),
]
PAIR2HEX = {p: format(i, 'x') for i, p in enumerate(PAIRS)}


def core_values_decode(text):
    # 1) 去掉所有空白，得到纯词序列
    t = ''.join(text.split())
    # 2) 按每 2 个字切一个词
    words = [t[i:i + 2] for i in range(0, len(t), 2)]
    # 3) 每 2 个词拼成一个词对，查表得到 hex 字符
    hexstr = ''
    for i in range(0, len(words) - 1, 2):
        pair = (words[i], words[i + 1])
        hexstr += PAIR2HEX.get(pair, '')
    # 4) hex -> 字节 -> 明文
    if len(hexstr) % 2:
        hexstr = hexstr[:-1]
    return bytes.fromhex(hexstr).decode('utf-8', errors='ignore')


data = "把核心价值观文字粘这里"
print(core_values_decode(data))
```

> ⚠️ **重要提醒**：`PAIRS` 的排列方式**各版本实现可能不同**。
> 如果你自己写的脚本解出来是乱码，**别怀疑题目，直接换在线工具** ——
> 工具的作者实现才是平台使用的标准。写这段代码的目的是让你**看懂原理**，
> 不是为了替代工具。

## 5. 关键知识点
- **核心价值观编码**：中国 CTF 圈的"特色编码"，把一个字节的十六进制表示替换成中文词。
- **它不是加密**，是**编码（Encoding）** —— 没有密钥，任何人都能还原。
- **编码 vs 加密**：
  - 编码：为了传输/存储方便，**可逆、无密钥**（Base64、URL 编码、Hex、核心价值观）
  - 加密：为了保密，**需要密钥**（AES、RSA、凯撒密码）
- 判断技巧：看到**规律性极强的中文词序列**，八成是核心价值观 / 与佛论禅 / 熊曰 之类的圈内编码。

## 6. 常见坑
- 复制时**丢了空格**不影响（解码前会去掉所有空白），但**丢字**一定会错。
- 手工查表太容易错，**新手一律用在线工具**，把时间花在理解原理上。
- 解出来是十六进制字符串（`666c6167`）而不是明文？再丢进 CyberChef 的 `From Hex`。
